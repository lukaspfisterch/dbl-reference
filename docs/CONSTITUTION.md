# Constitution

## What This Is

dbl-reference is the executable specification of DBL invariants.

## Governing Principles

1. **Authoritative bounds define scope.** This repo validates, it does not compose systems.
2. **Decision primacy.** Only DECISION events are authoritative.
3. **Observational non-interference.** Observational data cannot affect authoritative state.
4. **Falsifiable.** Every claim is testable.

## What This Is Not

- Not a system composition.
- Not infrastructure.
- Not a runtime.
